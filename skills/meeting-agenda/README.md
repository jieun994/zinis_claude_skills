# 회의 아젠다 준비 (meeting-agenda)

## 뭐 하는 스킬인가요?

**회의 시작 전에** 다룰 안건, 물어볼 것, 오늘 꼭 정하고 나와야 할 것을 미리 뽑아줍니다.
지난 회의록을 같이 주면 **아직 안 끝난 TO-DO와 미해결 이슈를 자동으로 끌어와서** 이번 아젠다에 올려줍니다. "지난번에 미정으로 남긴 거 뭐였더라" 하고 회의록을 다시 뒤적일 필요가 없어요.

회의가 끝난 뒤 회의록을 만드는 건 `meeting-minutes` 스킬이 합니다. 이 스킬은 그 **앞단**이에요.

| | 언제 쓰나 | 스킬 |
|---|---|---|
| 회의 **전** | "내일 미팅에서 뭘 물어보지?" | **meeting-agenda** (이 스킬) |
| 회의 **후** | "녹취록으로 회의록 만들어야 해" | meeting-minutes |

## 어떻게 쓰나요?

Claude에게 이렇게 말하면 됩니다.

```
내일 오후에 그린마켓이랑 미팅 있는데 뭘 물어봐야 할지 정리해줘
```

지난 회의록 파일이 있으면 같이 주세요. 결과가 확 달라집니다.

```
다음주 킥오프 전에 안건표 좀 만들어줘. 지난 회의록 첨부할게
```

**바쁠 땐 이렇게만 해도 됩니다.**

```
이따 바로 A사 미팅인데 아젠다 좀
```

급한 상황(“지금”, “곧”, “10분 뒤”)이면 Claude가 되묻지 않고 바로 초안을 냅니다. 자료가 없으면 없는 대로 만들고, 모자란 부분은 `확인 필요`로 표시해줘요.

**필요한 건 딱 하나** — 이번 회의에서 뭘 얻어야 하는지 한 줄이면 됩니다.
("화면설계 확인받기", "결제 연동 방식 정하기" 정도면 충분해요.)

### 같이 주면 좋은 자료 (없어도 됩니다)

| 자료 | 왜 좋은가 |
|---|---|
| 지난 회의록 (엑셀) | 안 끝난 TO-DO·이슈를 자동으로 이번 안건에 올려줌 — **가장 효과 큼** |
| 메모 | 신경 쓰고 있던 지점을 안건으로 정리해줌 |
| 기획 산출물 (IA·요구사항 등) | `미정`, `TBD`로 남은 칸이 곧 "물어볼 것"이 됨 |

## 결과가 어떻게 나오나요?

대화창에 바로 체크리스트로 나옵니다. 회의 자리에서 노트북 켜놓고 보면서 체크하면 돼요.

```
## [그린마켓 앱 리뉴얼] 챗봇 요구사항 2차 회의 아젠다 — 2026-07-10

### 안건 (다룰 것)
- [ ] 1. [설계] 검색 처리 구조 수정본 확인
      (근거: 7/3 회의록 TO-DO#4 — 정민준, 완료희망일 7/8, 완료일 공란)

### 물어볼 것 (확인 필요)
- [ ] 플로우 영역 구분본은 언제까지 주실 수 있나요?
      → 7/3에 날짜를 못 정하고 넘어간 유일한 항목이라 이번엔 받아야 함

### 결정할 것 (오늘 못 정하면 일정에 영향)
- [ ] 학습데이터 반영 주체
      선택지: ① 챗봇 쪽 반영(빠르나 이중 관리) vs ② 본 사이트 단일 소스
      못 정하면: 챗봇 관리자 화면 설계를 시작할 수 없음
```

전체 예시는 [`samples/결과_예시.md`](samples/결과_예시.md)에서 볼 수 있어요.

**추가로 부탁할 수 있는 것**

- `"파일로 저장해줘"` → `.md` 파일로 저장
- `"고객사에 보낼 버전도 만들어줘"` → 속내(우려·협상 포인트)를 뺀 **공유용 정제본**을 따로 만들어줍니다

## 이 스킬이 지키는 원칙

가장 중요한 건 **뻔한 소리를 안 하는 것**입니다.

`1. 인사 2. 진행 현황 공유 3. 마무리` 같은 안건은 이미 알고 계시잖아요. 그래서 이 스킬은:

- 안건마다 **`(근거: …)`를 반드시 답니다.** 지난 회의록 몇 번 항목에서 나왔는지가 붙어요
- 근거를 못 찾은 항목은 안건에 섞지 않고 **`가정 — 확인 필요`**로 따로 빼둡니다
- 프로젝트 고유명사(화면명·기능명·날짜)가 하나도 없는 안건은 **스스로 걸러냅니다**
- 자료가 부족하면 **"일반적인 안건 위주입니다"라고 먼저 말합니다**

없는 이슈를 지어내서 회의 자리에서 곤란해지는 일이 없도록 만들었어요.

## 설정

| 설정 | 기본값 | 바꾸려면 |
|------|--------|----------|
| 출력 형태 | 대화창 체크리스트 | "파일로 저장해줘" |
| 공유용 정제본 | 안 만듦 | "고객사에 보낼 버전도 만들어줘" |
| 회의 유형 | 자동 판단 | "이건 킥오프야"처럼 말하면 그대로 |
| 급할 때 모드 | 급한 신호 있으면 자동 | "천천히 물어봐도 돼" |

## 준비물

지난 회의록 **엑셀**을 읽으려면 `openpyxl`이 필요합니다. 없다고 하면 이렇게 설치하세요.

```bash
pip install openpyxl
```

엑셀이 아닌 자료(메모, 워드, 붙여넣은 텍스트)는 설치 없이 바로 됩니다.
