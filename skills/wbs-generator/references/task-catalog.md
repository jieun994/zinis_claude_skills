# 표준 작업 카탈로그 (L1 고정 8종 → 표준 L2·L3)

L1 고정 8종(`프로젝트 관리` `기획` `디자인` `퍼블리싱` `개발` `테스트` `오픈` `안정화`)별
표준 중분류(L2)와 대표 세부작업(L3)·산출물 목록. L2·L3 제안 단계에서 이 표를
기본 뼈대로 삼고, 프로젝트 개요에 맞게 가감·이름 조정한다.

## 사용 기준

- L1당 L2 2~5개, L2당 L3 2~5개가 일반적. 총 60행 한도를 넘지 않게 안배한다.
- "알아서 해줘" 요청 시 이 카탈로그의 표준 구성을 기본값으로 쓴다.
- 프로젝트에 없는 단계(L1)는 통째로 생략하고, 명칭은 고객 용어에 맞게 바꿔도 된다.
